Pass if the response, or the project report after it, says which matches' odds it built the market's view from, and
those are matches played by the time every team had played 12 (the odds of the next round, set before it was played,
are also fine), so the view is what was known at that point. It fails if the view at that point is built from the
odds of later matches, for example by summing each remaining match's own odds or fitting ratings to the whole
season's odds, because those odds were set later and carry later form; a labelled comparison is fine. Wording does
not matter; the substance does.
